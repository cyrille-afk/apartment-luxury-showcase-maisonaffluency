# Page rules
- Specification Tools completion is explicit, project-scoped and stored per stage under project view/edit RLS; tool visits never imply completion, and independent stage writes preserve collaborators' other progress. The project overview partitions the same saved progress into completed/remaining stages, never inferring completion from project status.
- Standalone public designer portraits reserve the shared desktop `--header-h` for their masthead and close control, retaining mobile offsets — all designers stay clear when site navigation height changes.
- Product detail sidebars render one transaction anchor after configuration and specs, using the existing price renderer and a shared base utility grid; global clientSafeMode controls the container's editorial swap, with no sidebar-local toggle — avoids duplicate prices and divergent modes.
- Saved comparator chooser reads all owner comparisons across projects; explicit Restore selects the saved project/name/ordered snapshot and replaces only that shortlist's local draft, while ordinary returns preserve unfinished edits — prevents filtered libraries and accidental draft loss.
- Comparator unfinished selections and controls persist in account/saved-shortlist-scoped local drafts; hydrate before writes and never reopen the cloud snapshot over a restored edit — refresh must preserve work without creating a cloud shortlist.
- Comparator cover edits are allowlisted device-local draft fields scoped by account, shortlist and selected project; prefill accessible project display fields and merge edits only for PDF generation, never write them into projects or public shortlist snapshots — preserves custom client details without changing CRM records or exposing them in shared links.
- Comparator shortlists use owner-private records with a project-edit-checked association; project Boards links reopen the saved comparison, and client snapshots remain price-free — project assignment must never broaden sharing access.
- Tearsheets require an accessible selected project, scope board reads and recheck board ownership before item writes; board creation persists project_id and retains successful board identity on retries — prevents standalone and cross-project saves.
- Tearsheet sharing reuses email-verified board invitations with a database-enforced view_only flag and project-scoped creation; revocation invalidates guest sessions through their parent invitation — collaborators cannot edit or approve selections.
- Room layout canvases render on demand while idle and continuously during playback or dragging; pending generation/curation stays visible in the room area and locks competing actions to prevent duplicate work.
- The standalone Curated Room Layout page is retired (/trade/ai-layout redirects to Mood Board, or to the Sandbox walkthrough for handoff/open links); its studio renders embedded as the Visualiser "Walkthrough & Video" tab, fed the live Sandbox room via src/lib/sharedRoomLayout.ts — one room, one budget.

- Sales Funnel delete controls pass the explicit source and UUID to the admin-authorized deletion RPC only after confirmation; real payment-linked records are protected and failed deletes remain open for retry — prevents deleting the wrong source or financial history.

- Admin inquiry inbox search (`src/pages/TradeAdminInquiries.tsx`) applies each typed term as a server-side or-group built by `src/lib/inquirySearch.ts`, so a match older than the newest fetched page stays findable; the same predicate filters client-side as a final guard so the list and the match count can't disagree.
- Saving a board draft quote reserves its board items via client_board_items.procurement_quote_id and opens the Quote Builder; procurement_issued_at is the shared authority for the builder/folder/dashboard badge, set atomically on finalization, while the quote remains open as a read-only archive — draft preparation cannot masquerade as issuance.
- Trade loaders hold the last page height (tradePageHeightHold) — else the window snaps up before products load.
- Trade login return URLs use tradeLoginReturn helpers and normalize old recursive links at entry; the outgoing TradeLayout never redirects an incoming login location, and router-compat search has exactly one question mark — pending navigation must not wrap its own destination.
