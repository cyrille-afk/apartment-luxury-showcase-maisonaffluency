- Product-page "Add to Co-Pilot Workspace" appends to the global `projectInventory` (src/contexts/ProjectInventoryContext, sessionStorage `ma:project-inventory-v1`); ProjectAssetsDrawer lists it on both the 2D Layout Plan and the Axonometric Studio. Every spawn path (drawer click, plan drag-and-drop, CatalogDrawer) builds its PlacedObject via `createPlacedObject` (src/lib/placedObjectFactory.ts) — never a separate spawn path. The 2D plan (LayoutPlanCanvas) stores drop/pointer coordinates as room metres (x = position[0], y = position[2], origin at room centre) directly in the shared ActiveProjectContext objects, so Open Axonometric Studio carries the exact 2D layout into the 3D scene.
- Dimension guides and clearance indicators share one geometry module, src/lib/layoutGuides.ts (oriented-footprint distance, wall gaps, tightestGap, nearestClearance): the 2D plan draws cm dimension lines and colour-coded clearance spans for the selected piece (Guides toggle), the plan and Axonometric headers show the tightest-gap chip, and the 3D inspector shows the selected piece's nearest clearance. Thresholds: comfortable ≥ 0.9 m, tight ≥ 0.6 m (matches the coffee-table gap rule), blocked below; colours use the success/warning/destructive tokens only.
- Project Assets removal filters shared project objects by inventory-instance provenance; legacy placements match the full saved configuration, and both view selections reconcile against remaining objects — removes geometry and plan vectors together without deleting another configured instance.
- Calibrated room photos use one four-corner homography for floor drops and a matching invertible camera projection; fixed letterboxed DOM photos replace environment backgrounds, OrbitControls stay disabled, ContactShadows provide a transparent catcher without a coplanar depth-writing plane, and calibration persists alongside the Sandbox — keeps photos, furniture and drag rays aligned. Floor dimensions come from project bounds; vertical projection assumes a centred 60-degree lens, not recovered camera metadata.
- Workspace plan ↔ 3D share one room-metre space (origin = room centre, plan y = 3D z); ProjectArchitecture compiles bounds, blueprint (same slice crop) and plan columns into the 3D room, replacing showroom architecture, and drags/inspector edits clamp to walls with columns as obstacles — so the plan and both 3D views can't drift.
